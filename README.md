# Agenda

App Android de agenda de alunos: cadastre e consulte alunos com nome, telefone e e-mail.

## Telas

- `ListStudentActivity`: lista de alunos
- `FormStudentActivity`: formulário de cadastro
- `ShowStudentActivity`: detalhes do aluno

## Stack

Kotlin, AndroidX AppCompat e Material Components. minSdk 21.

## Como rodar

Abra no Android Studio e rode o módulo `app`.
